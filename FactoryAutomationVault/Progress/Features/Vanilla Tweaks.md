# Overview

A list of every tweak done to the base game functionality by Factory Automation

# Tweaks
## Recipes
- Logs -> Removed plank recipes
- Planks -> Removed stick recipes
- Removed wooden tool recipes
- Ores -> Removed ingot furnace smelting recipes
- Clay -> Removed brick furnace smelting recipes
## Mining Levels
- Deepslate (and all deepslate ores) requires iron pickaxe
- Iron and Lapis require iron pickaxe
- Diamond and Emerald require bronze pickaxe
- Gold requires diamond pickaxe
- Netherite requires steel pickaxe
## Drops
- Copper ore drops 1 raw copper
## Miscellaneous
- Punching trees damages players (if you punch too long)
- Iron tools now have 320 durability
